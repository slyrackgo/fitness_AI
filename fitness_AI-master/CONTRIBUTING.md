# Contributing

Thank you for your interest in contributing to this project. Please follow these basic guidelines:

- Fork the repository and create a feature branch for your changes.
- Write clean, well-tested code and keep changes focused.
- Open a pull request against `master` with a descriptive title and summary.
- Add tests for new features and run `make check` locally before opening a PR.

For security-sensitive issues (private disclosure), see `SECURITY.md`.
