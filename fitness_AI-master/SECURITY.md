# Security Policy

If you discover a security vulnerability in this project, please report it privately to the maintainers so it can be addressed promptly.

Preferred contact: create an email to `SECURITY@your-org.example` (replace with real address) or open a private issue if appropriate.

What to include:
- A clear description of the issue and steps to reproduce.
- Affected versions and environment details.
- Any PoC or exploit code (if available).

We will respond within 7 business days. Do not disclose the vulnerability publicly until a fix has been released.
