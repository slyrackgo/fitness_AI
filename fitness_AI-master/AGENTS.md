AGENTS.md
===========

Короткая инструкция для ИИ‑агентов и обзор репозитория.

Цель
- Быстрая карта модулей, безопасные границы и разрешённые действия для автоматизированных агентов.

Репозиторий — краткая карта
- `eureka/eureka` — сервис регистрации (обязателен для локального запуска сервисов)
- `userService` — управление пользователями
- `activityService/activityService` — сбор и обработка событий активности
- `AI_Service/AI_Service` — генерация рекомендаций и ML-логика
- `gateway/gateway`, `configServer/configServer` — сетевой шлюз и конфигурация

Разрешённые автоматические действия (пример)
- Предложить документационные правки (README, AGENTS.md, docs/*).
- Добавить `.env.example` и заменить явные секреты в YAML на placeholders.
- Добавить простые CI/Check-скрипты и заглушки (Makefile, scripts/check.bat).

Запрещено без человека
- Изменять бизнес-логику без четко оформленного задания, критериев приёмки и тестов.
- Внедрять/менять секреты или ключи API прямо в репозиторий.
- Автономно менять версии JDK/библиотек без согласования и тестов.

Проверка изменений
- Для каждой значимой правки требуется: описание цели, список изменённых файлов, команда для воспроизведения, тест/проверка и PR с чек-листом приёмки.

Контакты
- Храните handoff и decision log в `docs/decisions` и `docs/handoffs`.
